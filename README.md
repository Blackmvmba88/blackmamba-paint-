# BlackMamba Paint

BlackMamba Paint is a visual creation system built around an infinite canvas, time-native strokes, editable geometry, perspective intelligence, animation, and eventually visual-art learning and 3D workflows.

> First build a great drawing engine. Then teach it to see.

## Product principles

- The artist stays in control.
- Empty space costs nothing; content does.
- Strokes are geometry + input + time, not baked pixels.
- Analysis and assistance are non-destructive by default.
- Everything detected by the system should become inspectable and editable.
- 2D, 360/cylindrical, spherical, animation, and future 3D share one spatial model.

## Initial milestone — First Stroke

The first milestone is intentionally small:

1. Create a document.
2. Draw strokes.
3. Pan and zoom an infinite canvas.
4. Edit a stroke.
5. Undo and redo.
6. Save, close, reopen.
7. Recover exactly the same world.

The roadmap and architecture are being developed in `docs/`.
